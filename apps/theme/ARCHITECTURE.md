# Crystal Basket Shopify theme — architecture

Goal: the Shopify Online Store renders the same site as `apps/web` (same markup classes, tokens, copy, images and
interactive components) so crystalbasket.store can point at Shopify and GitHub Pages can be switched off.

## Layout of this package

```
apps/theme/
  scripts/build-data.ts    copies images + fonts into theme/assets (flattened names), writes snippets/cb-img.liquid
  scripts/sync-shopify.ts  Admin API: metaobject definitions, entries, product metafields, Files, pages, redirects, menus
  src/styles/theme.css     Tailwind v4 entry: tokens, utilities, keyframes (mirror of apps/web/src/app/globals.css)
  src/islands/main.tsx     island runtime: mounts React components into [data-island] elements
  src/components/…         React components ported from apps/web (Link -> <a>, Next hooks removed)
  src/lib/…                cart (Shopify Ajax API), wishlist, subscribe, sizes, contact, config
  src/vanilla/…            header behaviour, scroll reveal, Lenis smooth scroll, wishlist/bag badges
  theme/                   the Shopify theme that `shopify theme push --path theme` uploads
```

## Rules

1. **Classes are copied verbatim** from the React components so Tailwind produces identical CSS. Tailwind scans
   `theme/**/*.liquid` and `src/**/*.tsx` (see `@source` in theme.css). Dynamic class names must be written out in full.
2. **No hex in sections or components**: use the `cb-*` tokens (same rule as apps/web, `scripts/check-tokens.sh`).
3. **Static markup lives in Liquid; behaviour lives in islands or vanilla modules.** An island that has visible
   initial state (BuyBox, FilterBar, BagButton, WishlistButton) is first rendered by Liquid with the same markup, then the
   React island replaces it on mount, so nothing shifts.
4. **Content comes from Shopify**: products + variants from the product object, extra product facts from
   `product.metafields.crystal.*`, stones / intentions / stacks from metaobjects (`shop.metaobjects.stone`,
   `.intention`, `.stack`). The catalog JSON in `packages/catalog` is the migration source, pushed by `sync-shopify.ts`.
5. **Images**: product photos are Shopify product images. Stone, bead, intention and stack photos are Shopify Files
   referenced from metaobject `file_reference` fields. Hero / about / build teaser / stacks band photos are theme assets
   rendered through `{% render 'cb-img' %}` with the WebP variants generated by `scripts/responsive-images.py`.

## Islands

Mount point: `{% render 'cb-island', name: 'BuyBox', props: json_string %}` renders
`<div data-island="BuyBox"><script type="application/json">…</script><!-- optional Liquid placeholder --></div>`.
`src/islands/main.tsx` reads the JSON, mounts the component with `createRoot`, replacing the placeholder children.

| Island | Props | Placeholder |
|---|---|---|
| `SearchDialog` | `{ items: SearchItem[] }` | none; opens on `cb:search` window event |
| `CartDrawer` | none | none |
| `BagButton` | none | the same button markup with count 0 |
| `WishlistButton` | `{ id, label?, className? }` | the same button markup |
| `FilterBar` | `{ intentions, stones, total, gridId }` | none (container keeps `min-height`) |
| `BuyBox` | `{ id, name, priceAED, compareAtAED?, sizes, inStock, freeDeliveryAED, deliveryFeeAED, deliveryCopy }` | static price + size + button markup |
| `StackBuilder` | `{ products, intentions, discountPct, presets }` | none |
| `BraceletBuilder` | `{ stones, intentions, pricing, goldBead }` | none (container keeps `min-height`) |
| `OfferPopup` | none | none |
| `NewsletterBar` | none | none |
| `WishlistClient` | `{ items }` | none |

Site configuration reaches islands through `window.CB` (snippet `cb-config`): name, city, currency, deliveryFeeAED,
freeDeliveryAED, deliveryCopy, stackDiscountPct, welcome `{pct, code}`, custom pricing, flags, whatsapp, email, instagram,
routes (`shop`, `stacks`, `build`, `intentions`, `stones`, `sizeGuide`, `care`, `faq`, `delivery`, `returns`, `contact`,
`privacy`, `disclaimer`, `wishlist`, `about`), `offerImage`.

## Cart

`src/lib/cart.ts` keeps the `useCart()` API of apps/web but talks to Shopify's Ajax API on the same origin:
`/cart.js`, `/cart/add.js`, `/cart/change.js`, `/products/<handle>.js` (variant lookup by "Wrist size" / option values).
`checkoutUrl` is `/checkout`. Line attributes become Shopify line item `properties`.

## Routes

| apps/web | theme |
|---|---|
| `/` | `/` |
| `/shop/` | `/collections/all` |
| `/products/<slug>/` | `/products/<handle>` |
| `/intentions/`, `/stones/` | `/pages/intentions`, `/pages/stones` |
| `/intentions/<id>/`, `/stones/<id>/` | metaobject pages (`metaobject.system.url`) |
| `/stacks/`, `/build/`, `/about/`, `/size-guide/`, `/care/`, `/faq/`, `/disclaimer/`, `/delivery/`, `/returns/`, `/contact/`, `/privacy/`, `/wishlist/` | `/pages/<same>` |

Every old path gets a 301 in `sync-shopify.ts` once the domain moves.

## Metaobject definitions (type: fields)

- `stone`: name, keywords (list), chakra (list), zodiac (list), color, palette_1, palette_2, description, water_safe,
  sun_safe, tier, mineral, mohs, found_in, worn_for, wrist, wrist_why, water_note, pairs_with (list stone refs),
  image (file), bead (file, builder sprite). Handle = catalog id. Online store pages on.
- `intention`: name, short, tagline, triad (list), description, chakra (list), palette_1, palette_2, sort_order,
  image (file), seo_description, definition, wrist, stones (list stone refs), faq (json `[{q,a}]`). Online store pages on.
- `stack`: name, intention (ref), products (list product refs), price_aed, description, featured, image (file).

Product metafields, namespace `crystal`: intention (ref), secondary_intentions (list refs), stones (list refs), gold_accent,
style, triad (list), promise, body, affirmation, includes (list), featured, bestseller, is_new, leaving_soon, seo_title,
seo_description, subtitle. Stock, price, compare-at and wrist sizes come from the product itself.
